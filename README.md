# 探光 · 好奇心与生活灵感

一个适合 iPhone 的轻量 PWA。它帮助好奇心既有入口也有出口，同时记住想去的店、想吃的美食、想读的书和想体验的生活。

## 核心设计

- **方向层**：记录年度问题和本月唯一主要问题。
- **安静的 Inbox**：首页只显示数量，不展示全部问题，减少注意力被劫持。
- **本周候选**：从 Curiosity Inbox 主动挑选，最多 3 个。
- **探索小契约**：开始前设定目的、探索层级、时间上限、结束条件和“这次不研究什么”。
- **分支停车场**：探索中冒出的新问题只记录，不切换；结束时再送回 Inbox。
- **Life Wishlist**：保存探店、美食、书、电影、地点、活动和想联系的人。
- **不知道做什么**：根据可用时间、当前能量和意图，只推荐 1–3 个选择。
- **轻量复盘**：结束探索时自动留下答案、证据和下一步。

## 探索层级

- 快速知道：通常 10–15 分钟，获得基本答案。
- 初步理解：通常 30–45 分钟，能够用自己的话解释。
- 帮助决定：通常 60–90 分钟，获得足够信息作出选择。
- 形成产出：转化为有期限和交付物的独立项目。

## iPhone 使用

1. 用 Safari 打开 <https://huangljing.github.io/curiosity-compass/>。
2. 点击底部“分享”。
3. 选择“添加到主屏幕”，名称保留为“探光”。
4. 以后像普通 App 一样打开。

## 数据与隐私

所有问题、愿望、规划与复盘都默认保存在当前设备的浏览器本地存储中，不会随代码上传到 GitHub。升级会自动迁移旧版 `tanguang-v1` 数据。

> 清除 Safari 网站数据可能同时删除本地记录。当前版本保持轻量，暂不加入账号和云同步。

## 设计原则

1. 收下来不等于现在解决。
2. 好奇可以无限，但本周候选最多三个，同时只探索一个。
3. 开始前先定义“到哪里结束”。
4. 新分支先停放，当前探索不切换。
5. 不知道做什么时，先判断时间、能量和意图。
6. 生活愿望不是研究项目，选中以后去体验。

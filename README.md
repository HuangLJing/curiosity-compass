# 探光 · 好奇心探索

一个适合 iPhone 的轻量探索管理 PWA。它不是待办清单，而是给好奇心一个出口：收集问题、选定今日重心、推进探索状态，并留下很短的复盘。

## MVP 功能

- Curiosity Inbox：快速收下刚冒出的疑问
- 今日探索重心：用星标只聚焦一个问题
- 状态流转：想探索 → 进行中 → 已理解 → 转化项目
- 领域标签：工作、科普、技术、生活、其他
- 下一步：为每个问题写下一个最小行动
- 轻量日复盘：记录“发现了什么 / 下一步是什么”
- 离线可用：安装后可在没有网络时打开
- 本地存储：所有问题和复盘只保存在当前设备浏览器中，不上传到 GitHub

## iPhone 使用

1. 用 Safari 打开 GitHub Pages 地址。
2. 点击底部“分享”。
3. 选择“添加到主屏幕”，名称保留为“探光”。
4. 以后像普通 App 一样从主屏幕打开。

> Safari 的网站数据被清除时，本地记录也可能被清除。MVP 暂不加入账号、云同步和复杂统计，以保持轻量。

## 本地预览

直接用静态网站服务器打开本目录即可。项目不需要构建步骤或第三方依赖。

## 设计原则

1. 先记录，不强迫立刻探索。
2. 每天只点亮一个重心。
3. 状态帮助看见进展，不制造压力。
4. 工具保持足够简单，把时间还给真正的探索。
